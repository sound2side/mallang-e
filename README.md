# MALLANG-E

A browser prototype of MALLANG-E, a modular handheld game device. It was made for the 핀업컨셉디자인어워드 (Pin Up Concept Design Award).

Open `index.html` in a browser. There is nothing to install.

## The device

- Two magnetic sockets take swappable input modules: 말랑 버튼 (squishy button), 다이얼 (dial), 십자키 (D-pad), 클리커 (clicker) and 조이스틱 (joystick).
- The screen is not a touchscreen. Everything is controlled with the modules and the hardware buttons.
- **Ring button**: tap to go back, hold to open the current game's menu.
- **Side switch**: sound on/off.
- Colour swatches, camera (saves a photo of the device), home and flip buttons sit beside the device.

## Games

| Game | What you do |
|---|---|
| 주민 만들기 (Resident Maker) | Build your own resident, name it and save it |
| 광장 (Plaza) | Saved residents wander, chat and nap |
| 바운스볼 (Bounce Ball) | Your resident bounces through 5 stages. Squeeze harder to jump higher |
| 낚시 (Fishing) | Let line out and reel in with the dial. 9 species, including a legendary one |

## Keyboard

| Key | Action |
|---|---|
| ← → ↑ ↓ | D-pad |
| W A S D | Joystick |
| Q E | Dial |
| Space | Clicker |
| X | Squishy button (hold) |
| I | Menu |
| Esc / Backspace | Back |
| Enter | Confirm / name entry |
| M | Sound |

Saved residents and progress stay in your browser's local storage.
